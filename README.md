- **Topic:** Database-driven Web Application with PHP & MySQL  

---

## 📌 Project Description

A full **online menu management system** built as a database-driven web application. The project demonstrates database design (ER modeling), relational schema implementation, and full CRUD operations through a PHP web interface.

Features include:
- User registration and login system
- Product/menu browsing and viewing
- Shopping cart and checkout flow
- Admin panel for managing products and orders
- ER diagram and relational schema design

---

## 🛠️ Technologies Used

- **PHP** — backend logic
- **MySQL** — relational database
- **HTML / CSS / JavaScript** — frontend
- **Bootstrap & jQuery** — UI framework
- **Apache Server** — XAMPP or WAMP recommended

## 🚀 How to Run

1. Install **XAMPP** or **WAMP**
2. Copy the `app/` folder into `htdocs/` (XAMPP) or `www/` (WAMP)
3. Import the database:
   - Open phpMyAdmin at `http://localhost/phpmyadmin`
   - Create a new database and import the SQL file from `app/database/`
4. Start **Apache** and **MySQL**
5. Open your browser at: `http://localhost/app`
